如何安裝繁體中文化

星際公民目前沒有官方中文。這裡使用我製作的 SC 語言包合併台：把簡體中文漢化包和 ExoAE 英文資訊包合併成繁體中文 global.ini，整個過程在瀏覽器裡完成，檔案不會上傳到任何伺服器。

🌐 打開語言包合併台 GitHub 專案頁

✨ 這個語言包有什麼

  • 繁體中文介面：台灣正體加台灣用語（例如「激光」會變成「雷射」）
  • 零件等級看得懂：例如 MIL-1C "Bracer" 會顯示成 軍規1C-Bracer（軍規、民用、工業、隱形、競速）
  • 任務資訊更完整：任務標題直接標出聲望與藍圖，貨運任務附上路線
  • 飛船中英並列：例如「黑彎刀」下一行是「Cutlass Black」，跟外國玩家溝通也不怕
  • 地點中英並列：例如「Nyx I 尼克斯 I」，方便對照英文攻略
  • 礦石名稱精簡：中文加英文縮寫和 RS 值，挖礦時一眼看懂
  • 看得到中文聊天：內建中文輸入解碼表，其他玩家用下方轉換器打的中文，你的遊戲也能正常顯示

🚀 方法一：三步驟安裝（推薦）

1

打開合併台，一鍵匯入

打開 SC 語言包合併台，按第 1 步的 「一鍵匯入並合併」，等它顯示合併完成。

2

下載語言包

按第 2 步的 「下載 global.ini（.zip）」，檔案會存到你的「下載」資料夾，不用解壓縮。

3

執行安裝器

下載 SC-zhTW-Installer.exe（只要下載一次），先關閉遊戲再雙擊執行。它會自動找到遊戲的 LIVE 資料夾和「下載」資料夾裡最新的語言包，確認後就安裝完成，重新開遊戲就是繁體中文。

💡 安裝器幫你做了什麼：
  • 把語言包放到 LIVE\Data\Localization\chinese_(traditional)\global.ini
  • 把 user.cfg 的語言設定改成繁體中文（其他設定保留）
  • 舊的 global.ini 和 user.cfg 會先備份到 LIVE\語言包備份\
  • 遊戲裝在 Program Files 時，會詢問是否用系統管理員身分重新開啟，按「是」就好

🔄 遊戲改版後怎麼更新？

每次遊戲改版後，舊的語言包可能會出現空白或缺字。重新做一次第 1、2 步下載新的語言包，再執行安裝器，選擇 「更新中文化」即可。

↩️ 想變回英文？

執行安裝器，選擇 「移除中文化（變回英文）」。它只會把語言設定改回英文，中文語言包會保留，之後想換回中文隨時可以。

🛠️ 方法二：手動安裝（不用安裝器）
  1. 在合併台按 「直接下載 global.ini」（下載的是 zip 的話先解壓縮）。
  2. 找到遊戲的 LIVE 資料夾。預設是 C:\Program Files\Roberts Space Industries\StarCitizen\LIVE，裡面會有 Data.p4k 和 Bin64。裝在別處的話，打開 RSI 啟動器 → Settings → Games，看 Library Folder 的位置。
  3. 在 LIVE 裡建立資料夾 data\Localization\chinese_(traditional)\（名稱要完全一樣，包含括號和底線）。
  4. 把 global.ini 放進去。不要用記事本另存，以免編碼被改掉（必須是 UTF-8 with BOM）。
  5. 在 LIVE 資料夾打開 user.cfg（沒有就新增，記得開啟「副檔名」顯示，確認不是 user.cfg.txt），加入下面兩行；已經有 g_language 的話就改掉： 
    g_language = chinese_(traditional)
g_languageAudio = english
    第二行讓遊戲語音維持英文。
  6. 重新啟動遊戲。想變回英文，把那一行改成 g_language = english。

翻譯來源：CitizenWiki 中文社群（42kit 半漢化包）、ExoAE、MrKraken、星際公民汉化组。這是非官方的粉絲專案，使用前請閱讀 使用者協議。CIG 目前允許玩家使用自訂的 global.ini，但政策可能隨時變更。
