地面戰技巧 (地堡任務)

行前準備與配裝建議

  • 護甲選擇：護甲分為輕、中、重型，減傷比例分別為 15%、30%、40%。為了提高生存率，強烈建議穿著重甲。您可以前往太空站購買 ADP 系列 裝甲。
  • 武器搭配：建議攜帶 步槍 + 狙擊槍 的組合，並記得為武器購買並裝備瞄具 (Optics)。
  • 醫療設備：一定要在裝備欄位配置一把獨立的 醫療槍 (Medical Gun)，這樣受傷時才能有效補血與治療。
  • 工具槍 (Multi-Tool)：建議配置 牽引槍 (Tractor Beam Attachment)。您也可以視情況攜帶礦槍接頭，但牽引槍是搬運物資或屍體的必備工具。

❓ Q&A: 為什麼不建議使用多功能工具槍的醫療模組？

因為在激烈戰鬥中，按下 5 拿出多功能工具槍時，如果上面裝的是牽引槍，你可能還需要再切換一次接頭才能使用醫療功能，這會錯失救命時機。此外，若玩家受到深度受傷 (Tier injuries)，多功能醫療槍是無法治療的，必須使用獨立的醫療槍 (Medical Gun) 才能應對。

1. 接受保全任務 (Mercenary)

按 F1 打開 MobiGlas，進入 Contract Manager (合約管理器)。在 Mercenary (傭兵) 標籤下，尋找 "Defend Site" 或 "Provide Backup" 等字眼的任務。這些通常被玩家稱為「地堡任務 (Bunker)」。這類任務風險相對較低，且能穩定賺取 aUEC 並搜刮敵方裝備。

2. 敵我識別 (IFF)

進入地堡後，千萬不要見人就開火！

  • 友軍 (當地保全): 頭頂上通常會有藍色倒三角形標記，穿著該星球專屬顏色的護甲 (例如微科星是白色/灰色，十字軍星是藍色)。
  • 敵軍 (九尾海盜 Nine Tails 等): 沒有標記，護甲顏色多為紫紅色、黑色等混搭風格。
  • 如果不小心擊殺了友軍，您將獲得 CrimeStat (犯罪等級)，任務會直接失敗，並且會被防空炮塔攻擊。

3. 基本戰鬥走位與掩護

星際公民的 AI 雖然有時會卡頓，但準度非常高。切勿站在空曠處與敵人對槍。

  • Q / E: 左右探頭 (Leaning)。利用牆角作為掩體，只露出頭部進行射擊，能大幅降低受傷機率。
  • Ctrl / C: 蹲下與趴下。降低身姿能減少受彈面積並提高射擊穩定度。
  • Shift: 衝刺。在空曠處移動時保持衝刺，尋找下一個掩體。

4. 醫療與倒地處理

  • 血量與倒地：左下角的 UI 有一個 + 符號代表您的血量。當血量歸零時，角色就會倒地 (Incapacitated) 並需要其他玩家救助；若在倒地後持續受到傷害，則會直接死亡。
  • 流血狀態：若受傷後介面上出現「水滴」符號，代表您正在流血，血量會持續下降，此時必須盡快使用醫療裝備治療。
  • 醫療道具：主要有 醫療槍 (按 3 裝備) 與 醫療筆 (按 4 裝備)。這些道具都可以在各大醫療站購買。
  • 操作方式：
    • 醫療槍 (3)：拿出來後，按下 B 鍵將槍口對著自己，接著按 滑鼠左鍵 即可進行治療。
    • 醫療筆 (4)：按下 滑鼠左鍵 是治療自己；按下 滑鼠右鍵 則是治療別人。
  • ⚠️ 用藥警告：治療時請注意用藥狀況 (BDL)。若用藥太高，角色會進入藥物過量狀態，導致畫面模糊，嚴重時甚至會持續扣血至死亡。
