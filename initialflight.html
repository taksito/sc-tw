實戰練習：飛到軌道太空站

把前面學到的全部串起來，完成你的第一次完整航行！

1. 啟動與起飛離港

坐上駕駛座後，請牢記以下三個起飛前最重要的按鍵：

  • U 鍵：啟動飛船電源。
  • I 鍵：開啟飛船推進器（或直接按 R 一鍵準備起飛）。
  • ALT + N：呼叫機庫門開啟 (自動請求起飛許可)。

完成啟動並等待機庫門完全打開後：

  • 按 Space (空白鍵) 垂直向上平移。
  • 滑鼠控制機頭方向，W/S 控制前進後退，A/D 左右平移。
  • 離開機庫後，按 N 鍵收起起落架。

2. 飛往軌道空間站

飛出大氣層後，按 F2 打開星圖 (Starmap)。在您當前星球的軌道上尋找空間站 (例如 New Babbage 上方是 Port Tressler)。點擊空間站並選擇 Set Route (設定路線)。

按 B 進入量子模式，對準目標點，等充能與校準完成後長按 B 進行量子跳躍 (Quantum Travel)。抵達後，按下 ALT + N 呼叫空間站降落服務，根據指示圖標降落並進入空間站，完成您的第一次航行！

📦 下一步：先跑貨運任務練習

能穩定起飛、量子航行、降落之後，建議先從貨運任務開始，用實際任務練習控制飛船：

  • 不用戰鬥：專心練起降、量子航行和在機庫、停機坪精準停船。
  • 會一直起降：每趟都要取貨、送貨，起降次數多，進步最快。
  • 邊練邊賺錢：貨運是 4.10.2 最賺錢的職業，新手小船也能接入門任務。
  • 順便學會貨梯與牽引光束：這些操作在其他職業也會用到。

  • ⚡ 第一個任務：Covalex 直達任務

    一個取貨點、一個送貨點，最適合練手。一步一步帶你從接單到交貨。
