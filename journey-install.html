註冊與安裝

註冊帳號、選遊戲包、下載啟動器，把星際公民裝進你的電腦。

📝 步驟 1：註冊 RSI 帳號

🎮 步驟 2：購買遊戲包

要進入遊戲，一定要買一個遊戲包 (Game Package)，單買飛船是無法進入遊戲的。

  • 入門首選：附 Aurora Mk II 的入門遊戲包（例如 First Flight Pack），內含遊戲本體、一艘 Aurora Mk II、開局遊戲幣，部分版本還附 Golem、Fortune、Intrepid 的 30 天租借。
  • 預算多一點：Avenger Titan 的遊戲包，是公認最好用的新手船，有 8 SCU 貨艙可以跑貨。
  • 遊戲包價格會隨活動調整，以官網為準。想用現金買更大的船，請看 CCU 現金購船。
💡 先試玩再買：IAE（每年 11 月）、Invictus（5 月）等活動常有 Free Fly 免費試玩，可以先確認電腦跑不跑得動。

💾 步驟 3：下載與安裝 RSI Launcher

1

下載啟動器

到官網下載頁 robertsspaceindustries.com/download 下載 RSI Launcher 並安裝。

2

登入帳號

打開 RSI Launcher，用剛剛註冊的帳號登入。

3

選擇安裝位置

在 Launcher 的 Settings → Games → Library Folder 選擇遊戲要裝在哪裡。一定要選 SSD（最好是 NVMe），並確認有 150 GB 以上的空間。

4

選擇 LIVE 並安裝

確認上方選的是 LIVE（正式服），按 Install 開始下載。檔案約 150 GB，網路慢的話可能要下載好幾個小時。

5

安裝中文化（選用）

下載完成後，可以照 中文化與輸入 頁的三步驟安裝繁體中文語言包。

📂 預設安裝位置

版本路徑
正式服 LIVEC:\Program Files\Roberts Space Industries\StarCitizen\LIVE
測試服 PTUC:\Program Files\Roberts Space Industries\StarCitizen\PTU
⚠️ C 槽空間不夠或不是 SSD 的話，請在 Library Folder 改成其他 SSD，例如 D:\Roberts Space Industries。之後安裝中文化、找 user.cfg 都會用到這個位置，記下來。

🛠️ 安裝出問題？

  • 遊戲檔案損壞：在 Launcher 的設定裡執行檔案驗證 (Verify)，會自動修復。
  • Launcher 卡住或登入異常：按 Ctrl + Shift + Alt + R 清除快取並登出，再重新登入。
